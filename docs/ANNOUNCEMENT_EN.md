# Introducing IA Local

IA Local is an open-source control panel for existing AI servers, HTTP agents and models, shared between desktop and browser. It preserves model locations and installations, checks service health, observes inference and records comparable evaluation conditions.

Features include Spanish/English UI and guides, reviewed integrations, opt-in LAN and external API connections, sequential evaluation and recoverable configuration. The macOS clean installer lets users choose application/data folders. Windows/Linux portable code shares the panel; check the verification report for actual platform test status.

Repository: https://github.com/sruizdeaguiar-svg/IA_Local

Contributions, reproducible tests and new adapters are welcome. Never share private data or credentials in issues. Apache-2.0 license.
