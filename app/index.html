Nuevo servidor o agente local
Elige un ejecutable de confianza. El asistente consulta su ayuda y usa OpenCode o Hermes con el modelo local activo, sin herramientas ni cambios en tus perfiles. Revisa la propuesta antes de guardarla. Los agentes exclusivamente CLI necesitan un adaptador HTTP específico.
La compatibilidad por formato es una declaración; la carga y la respuesta deben comprobarse. La app verifica loopback, identidad del proceso y puerto. No ejecuta comandos de instalación propuestos por la IA.


Servidor de la red local
API OpenAI compatible en la red privada conectada a este Mac. Usa la IP y termina en /v1. Conectar comprueba el inventario; no arranca ni detiene el proceso del otro ordenador. La prueba de respuesta puede cargar un modelo allí.
HTTPS verifica el certificado con la confianza del sistema. La clave queda en un archivo privado del usuario (0600, directorio 0700), nunca en el catálogo ni en los registros. Vacío conserva la clave al editar.

Manuales de uso / User guides
Manual de IA Local
Primer inicio y configuración
Abre IA Local y espera a «Supervisor conectado». En Configuración elige idioma, apariencia, frecuencia de telemetría, escaneo y actualizaciones. Guardar aplica preferencias compartidas a escritorio y web. La instalación limpia empieza sin cuentas, claves, modelos registrados ni acceso LAN. Si falta un motor, utiliza Integraciones; la app no descarga pesos automáticamente.
Control y estados
Cada tarjeta distingue proceso, salud y modelo. Arrancar prepara el servicio; Cargar seleccionado puede reservar memoria e inferir una comprobación. Detener solo finaliza el proceso identificado y gestionado. Arrancar todos deja en espera los motores que requieren pesos. Recuperar memoria descarga modelos locales y libera sus motores; los agentes y las cachés de macOS pueden seguir usando RAM. Los botones solo se habilitan cuando existe una operación válida.
Modelos y contexto
Autoriza la carpeta del SSD desde el Mac y pulsa Buscar modelos nuevos. GGUF, MLX y otros formatos conservan sus ubicaciones; no hay conversiones universales. Elige modelo, motor compatible y contexto; Guarda contexto antes de cargar. La tabla se actualiza al cambiar la selección. Un modelo listado no demuestra que esté cargado. Los formatos declarados para integraciones nuevas necesitan una prueba real. Los modelos remotos se identifican por su servidor y no se descargan al Mac.
Hermes y OpenCode
Arranca el agente y usa Abrir web cuando su interfaz esté disponible. Carga primero un modelo y pulsa Usar modelo activo en su tarjeta o en ambos. Se transfieren servidor, modelo y contexto para nuevas sesiones y se guardan copias. Hermes exige 64000 tokens como mínimo. OpenAI y otros proveedores existentes se conservan; la pasarela local no activa proveedores de nube. Las pruebas de asistentes usan perfiles aislados y no modifican los tuyos.
Añadir instalaciones con IA
En Integraciones pulsa Escanear instalaciones o activa el escaneo automático. Detectado no equivale a compatible ni arrancado. Selecciona Configurar o introduce nombre, tipo, ejecutable y puerto libre. Prepara una plantilla, carga un modelo local y elige OpenCode o Hermes para proponer argumentos a partir de --help. Revisa el JSON y guarda expresamente. Nunca se ejecuta una orden propuesta por el modelo sin esa revisión. Un agente solo de terminal necesita un adaptador HTTP; la IA no crea compatibilidad inexistente.
Servidores en otros ordenadores de la LAN
Añade nombre, URL privada terminada en /v1, contexto confirmado y clave opcional. Solo se aceptan IP de redes privadas conectadas al Mac; una nueva red puede exigir editar la dirección. Se rechazan Internet y redirecciones. HTTPS exige certificado válido; HTTP con clave requiere aceptación explícita. Guardar no conecta. Conectar consulta /models y añade el inventario; selecciona un modelo y prueba respuesta y streaming. Desconectar impide su uso desde IA Local y conserva el proceso remoto. No administra por SSH, ni garantiza descarga remota de pesos o actualización del otro ordenador.
Evaluación y optimización
La telemetría es pasiva; Evaluar consume recursos. Cierra otras cargas antes de probar. Llama usa calentamiento, pp512/tg128 y tres repeticiones; los demás motores usan aritmética, español, streaming y generaciones sintéticas. Evaluar todos recorre motores compatibles secuencialmente y libera memoria local. Optimizar todos busca parámetros solo donde hay adaptador; el resto se evalúa sin ajuste. Compara solo mismo modelo, cuantización, contexto, versión y método. Errores de memoria no son velocidades válidas. Velocidad no mide calidad. En LAN la latencia incluye red y no se conoce la memoria física remota.
Estadísticas
Control muestra CPU, GPU, RAM, generación en curso, última inferencia y medias del día, semana, mes y total. Tokens y fragmentos de streaming no son equivalentes. Los campos sin medición quedan vacíos; no se inventan cifras. La pasarela observa sus propias consultas y conserva métricas agregadas. Las conexiones directas pueden quedar fuera; la cobertura se indica en pantalla.
Límite GPU y permisos
Lee el valor actual antes de cambiarlo. Descarga modelos, selecciona el límite y aplica. El ayudante se instala una vez con autorización de macOS y solo permite leer o ajustar iogpu.wired_limit_mb. Restaurar usa el valor anterior verificado. Aumentar el techo no crea RAM; puede dejar poco margen al sistema. Desde web se exige administración y segundo factor, sin enviar la contraseña de macOS. El instalador limpio no instala el ayudante automáticamente.
Acceso web, usuarios y seguridad
En Red y usuarios crea una cuenta y activa LAN. Instala y verifica el certificado público en cada dispositivo. Configura segundo factor en el Mac para operaciones administrativas remotas. Administración gestiona usuarios e instalaciones; Control gestiona servicios y conversaciones; Lectura consulta el panel. Las claves remotas permanecen en archivos privados 0600 dentro del directorio 0700; no se exportan. No publiques los puertos en Internet. Escritorio y web comparten el mismo panel; iPad usa Safari.
Actualizaciones y recuperación
Consulta versiones oficiales, revisa alcance y pulsa Actualizar con el componente detenido. Se guarda copia antes de cambios compatibles con recuperación. Recuperar versión restaura la copia disponible. Un fallo de red deja el estado desconocido. No existe garantía de estar siempre actualizado. Integraciones nuevas y servidores remotos requieren su propio adaptador de actualización; no se ejecutan instaladores inventados por IA.
Instalación limpia y solución de problemas
Instalar IA Local permite elegir carpeta de aplicación y de datos o usar las de tu usuario. El paquete no incluye claves, usuarios, modelos ni conversaciones. Detecta requisitos de Python y muestra los que falten antes de instalar. Solo una instancia del supervisor puede usar el puerto 8040; no sustituye otra instalación activa. Si un servicio falla, abre Actividad y revisa su registro acotado. Puerto ocupado conserva el proceso ajeno. Modelo sin respuesta requiere revisar formato, arquitectura, contexto y memoria. Los textos de registros y respuestas se conservan en su idioma original.
APIs externas y FreeLLMAPI
En APIs externas elige OpenAI, Anthropic, Kimi, DeepSeek, FreeLLMAPI o Personalizado. Indica protocolo, URL, puerto exclusivo del adaptador, contexto confirmado, IDs opcionales y tu clave. Guardar deja la conexión desactivada. Conectar consulta modelos; si el proveedor no ofrece inventario, declara los IDs y verifica una generación. Importar FreeLLMAPI reutiliza su clave local sin mostrarla y conserva los perfiles actuales. Debes arrancar su servicio y configurar las claves de nube en su propio panel. Los protocolos OpenAI Chat Completions y Anthropic Messages son distintos; el adaptador no implementa todas sus extensiones. Las conversaciones y archivos que envíes pueden salir del Mac y generar costes. Arrancar todos y el asistente local no activan nube. Para evaluar o transferir un modelo externo debes seleccionarlo expresamente. Las cuentas sin saldo o permisos pueden listar modelos y fallar al generar.
Restablecer y recuperar
Configuración → Restablecer aplicación completa requiere escribir RESTABLECER. Desvincula instalaciones, elimina usuarios y preferencias de la configuración activa y cierra el acceso web. Conserva programas, pesos y conversaciones. Guarda antes una copia privada con integridad verificada. Recuperar último restablecimiento restaura usuarios y preferencias con servicios y red detenidos; vuelve a sincronizar los agentes si utilizaban la pasarela.
Windows y Linux
El lanzador portable abre este mismo panel en tu navegador y usa un directorio privado por usuario. Añade ejecutables mediante Integraciones y carpetas en Configuración. Los adaptadores nativos de macOS y el ajuste iogpu no se trasladan a estos sistemas. GPU NVIDIA se consulta si nvidia-smi está disponible; otros contadores ausentes se muestran como desconocidos.
IA Local user guide
First launch and settings
Open IA Local and wait for “Supervisor connected”. Settings controls language, appearance, telemetry, discovery and update intervals. Save applies shared desktop/web preferences. A clean installation starts without accounts, keys, registered models or LAN access. Use Integrations for missing engines; weights are not downloaded automatically.
Control and states
Cards distinguish process state, health and model state. Start prepares a service; Load selected may allocate memory and perform a readiness inference. Stop only terminates an identified managed process. Start all leaves weight-dependent engines waiting. Reclaim memory unloads local models and releases their engines; agents and macOS caches may still use RAM. Controls are enabled only when their operation is valid.
Models and context
Authorize the SSD folder on the Mac and select Find new models. GGUF, MLX and other formats keep their locations; no universal conversion is performed. Choose a model, compatible engine and context, then save context before loading. Comparison updates with the selection. A listed model is not proof that it is loaded. New integration format declarations need a real test. Remote models show their server and are not downloaded to the Mac.
Hermes and OpenCode
Start an agent and use Open web once its interface is available. Load a model, then use Use active model on its card or for both agents. Server, model and context are transferred for new sessions with configuration backups. Hermes requires at least 64000 tokens. OpenAI and other existing providers are retained; the local gateway does not enable cloud providers. Assistant tests use isolated profiles without editing yours.
Add installations with AI
In Integrations, scan installations or enable automatic discovery. Detected does not mean compatible or running. Choose Configure or enter a name, type, executable and free port. Prepare a template, load a local model and choose OpenCode or Hermes to propose arguments based on --help. Review the JSON and explicitly save it. Model-proposed commands are never launched without that review. Terminal-only agents require an HTTP adapter; AI cannot create unsupported compatibility.
Servers on other LAN computers
Add a name, private API URL ending in /v1, confirmed context and optional key. Only IPs on private networks connected to the Mac are accepted; moving networks may require editing the address. Internet targets and redirects are rejected. HTTPS requires a trusted certificate; sending a key over HTTP requires explicit acceptance. Saving does not connect. Connect queries /models and adds its inventory; select a model and test response and streaming. Disconnect prevents its use from IA Local and preserves the remote process. It does not use SSH or guarantee remote weight unloading or remote host updates.
Evaluation and optimization
Telemetry is passive; Evaluate actively consumes resources. Close other workloads before testing. Llama uses warmup, pp512/tg128 and three repetitions; other engines use arithmetic, Spanish, streaming and synthetic generations. Evaluate all runs compatible engines sequentially and releases local memory. Optimize all searches parameters only where an adapter exists; other engines are evaluated without tuning. Compare matching model, quantization, context, engine version and method. Memory errors are not valid speed results. Speed does not measure quality. LAN timings include network latency; remote physical memory is unknown.
Statistics
Control shows CPU, GPU, RAM, live generation, latest inference and day/week/month/all-time means. Tokens and streaming chunks are not equivalent. Missing measurements stay empty. The gateway observes its own requests and stores aggregate metrics. Direct connections may be outside its coverage; the UI states that coverage.
GPU limit and permissions
Read the current value first. Unload models, choose a limit and apply. The helper is installed once with macOS authorization and only reads or sets iogpu.wired_limit_mb. Restore uses the verified previous value. Raising the ceiling does not create RAM and can reduce system headroom. Web access requires administrator rights and a second factor without sending your macOS password. Clean setup does not install the helper automatically.
Web access, users and security
Create an account and enable LAN under Network and users. Install and verify the public certificate on every device. Set up the second factor on the Mac for remote administrative actions. Administrators manage users and integrations; Control users manage services and conversations; Read-only users view the panel. Remote keys remain in private 0600 files inside the 0700 data folder and are not exported. Do not expose ports to the Internet. Desktop and web share the same panel; iPad uses Safari.
Updates and recovery
Check official versions, review scope and update a stopped component. Supported changes are backed up first. Recover version restores an available backup. Network failure leaves version status unknown; periodic checks cannot guarantee perpetual freshness. New integrations and remote servers need their own update adapter; AI-invented installers are never executed.
Clean installation and troubleshooting
Install IA Local lets you select application and data folders or use user defaults. The package contains no keys, users, models or conversations. It detects Python requirements and reports missing ones before installation. Only one supervisor may use port 8040; an existing active installation is not replaced. For service failures, open Activity and review the bounded log. Port conflicts preserve foreign processes. For model failures check format, architecture, context and memory. Logs and model responses keep their original language.
External APIs and FreeLLMAPI
Under External APIs, select OpenAI, Anthropic, Kimi, DeepSeek, FreeLLMAPI or Custom. Enter protocol, URL, exclusive adapter port, confirmed context, optional model IDs and your key. Saving leaves the connection disabled. Connect queries models; if inventory is unavailable, declare IDs and verify generation. Import FreeLLMAPI reuses its local key without exposing it and preserves existing profiles. Start its service and configure upstream cloud keys in its own panel. OpenAI Chat Completions and Anthropic Messages are different protocols; the adapter does not implement all extensions. Messages and files you send may leave the Mac and incur charges. Start all and the local assistant never enable cloud. Explicitly select an external model before evaluation or agent transfer. Accounts without balance or permissions may list models but fail generation.
Reset and recovery
Settings → Reset entire application requires typing RESTABLECER. It unlinks installations, resets active users and preferences and closes web access. Programs, weights and conversations are preserved. A private integrity-checked backup is saved first. Recover last reset restores users and preferences with services and LAN stopped; synchronize agents again if they used the gateway.
Windows and Linux
The portable launcher opens this same panel in your browser and uses private per-user storage. Add executables through Integrations and model folders through Settings. Native macOS adapters and iogpu controls do not transfer to these systems. NVIDIA GPU metrics are read when nvidia-smi is available; unavailable counters remain unknown.


Proveedores de API externos
Los proveedores externos envían mensajes fuera del Mac y pueden tener coste. Guardar no conecta ni cambia los agentes. Arrancar todos no activa estas conexiones. No se sustituyen modelos locales por nube automáticamente.
Las claves se guardan en un archivo privado 0600 y no se devuelven al navegador. Vacío conserva la clave al editar. HTTPS verifica certificados. El adaptador Anthropic admite mensajes, imágenes, herramientas y streaming; no implementa todos los servicios o extensiones de cada API. El contexto se declara según tu modelo. Un inventario correcto no demuestra que tu cuenta pueda generar con todos sus modelos.
