# Contribuir / Contributing

Gracias por ayudar. Reproduce fallos con datos sintéticos y especifica SO/arquitectura, versión del motor, formato, contexto y pasos. Nunca adjuntes claves, tokens, contraseñas, conversaciones privadas ni datos personales.

Use an isolated `IA_LOCAL_HOME` **before importing core**. Run the Python suite and both Node UI checks documented in docs/DEVELOPMENT.md. Test real lifecycle transitions, health, cancellation and rollback for new adapters. A detected executable is not evidence of model compatibility. Keep native/web UI in the same HTML and translate new strings into both languages.

No shell-generated installers or generic kill-by-name/port. Preserve existing program/model/conversation data. Updates require official sources and recovery. Explain platform limits, test evidence and anything not verified in your pull request. Apache-2.0 applies to contributions; retain third-party notices.
